🚀 Image-to-3D Generator with Streamlit & Meshy API
このプロジェクトは、AI 3D生成プラットフォーム Meshy API を活用し、1枚の画像から高品質な3Dモデル（.glb）を生成・ダウンロードできるWebアプリケーションです。

🛠 搭載機能
直感的なUI: Streamlitを採用し、画像のドラッグ＆ドロップだけで操作可能。

非同期タスク管理:

APIへの生成リクエスト送信。

ポーリングによるリアルタイムな進捗監視（％表示）。

PBR（物理ベースレンダリング）対応: enable_pbr: true により、リアルな質感を伴う3Dモデルを生成。

自動ダウンロード: 生成完了後、即座にバイナリデータを取得し、ローカルへ保存可能。

📦 使用技術スタック
Frontend: Streamlit

HTTP Client: httpx（非同期通信に対応したモダンなクライアント）

3D Engine API: Meshy.ai

Format: GLB (gLTF Binary)

🚀 セットアップと実行
ライブラリのインストール:

Bash
pip install streamlit httpx
APIキーの設定:
コード内の MESHY_API_KEY 変数に、自身のMeshy APIキーを入力してください。

アプリの起動:

Bash
streamlit run your_filename.py
💡 技術的考察：システム・アーキテクチャの視点
APIオーケストレーション:
このコードは、リクエストの送信、状態の監視（ポーリング）、リソースの取得という「API連携の標準的なライフサイクル」を完璧に実装しています。

ステートレスな設計:
Streamlitの特性を活かし、複雑なバックエンドサーバーを構築することなく、ブラウザ完結型のツールとしてロジスティクス（データの流れ）を最適化しています。

ユーザー体験（UX）:
st.empty() を用いたステータスの動的書き換えや、st.balloons() による処理完了の通知など、エンジニアリングにおける「フィードバックの重要性」が考慮されています。
